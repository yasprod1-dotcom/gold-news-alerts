# تشغيل مجاني يصل إلى الهاتف والكمبيوتر مغلق

هذه نسخة مُعدة للنشر على GitHub Actions. تنزيل الملفات وحده لا يفعّلها؛ تحتاج إلى إعداد المستودع وأسراره وتشغيل أول فحص بنجاح.

## ١. ربط تلغرام مرة واحدة

شغل `start.cmd` على الكمبيوتر. انسخ التوكن من BotFather واضغط «لصق التوكن» ثم «اتصال بالبوت». اضغط «نسخ رسالة الربط»، ثم «فتح البوت في تلغرام»، وأرسل الرسالة المنسوخة إلى بوتك.

ستصلك رسالة تأكيد تحتوي على «معرف محادثتك للإعداد السحابي». احتفظ بهذا الرقم ومعه التوكن. يمكنك الآن إغلاق نافذة البرنامج. إذا ربطت البوت سابقًا، أعد فتحه وأدخل التوكن لتصلك رسالة التأكيد المحدثة.

## ٢. إنشاء المستودع

أنشئ مستودعًا جديدًا عامًا Public على GitHub، مثل `gold-news-alerts`. إعداد Public هو ما يجعل استخدام المشغل القياسي مجانيًا وفق سياسة GitHub الحالية. سيكون كود البرنامج متاحًا للآخرين؛ التوكن ومعرف المحادثة لا يُضافان إلى الملفات.

ارفع فقط ملفات حزمة النشر السحابي: `bot.py` و`cloud.py` و`.gitignore` و`README-CLOUD-AR.md`، ثم أنشئ ملف `.github/workflows/gold-news.yml` والصق فيه محتوى ملف الجدولة المرفق. يجب أن يكون `cloud.py` في جذر المستودع، وليس داخل مجلد فرعي. يجب أن يكون ملف الجدولة على الفرع الافتراضي.

إذا استخدمت واجهة GitHub لإنشاء ملف الجدولة، اختر Add file ثم Create new file، واكتب الاسم الكامل `.github/workflows/gold-news.yml`. ثم الصق محتوى الملف المرفق واحفظه.

لا ترفع مجلد التشغيل المحلي كاملًا: لا حاجة إلى `state.sqlite3` أو أي ملفات تحتوي بيانات حسابك. حزمة النشر المنفصلة المرفقة لا تتضمن هذه الملفات.

## ٣. إدخال السرّين

افتح داخل المستودع:

Settings → Secrets and variables → Actions → New repository secret

أضف سرّين، بالأسماء التالية حرفيًا:

- `TELEGRAM_BOT_TOKEN`: مفتاح BotFather.
- `TELEGRAM_CHAT_ID`: الرقم الذي أرسله البوت في رسالة التأكيد.

أدخل القيم مباشرة في إعدادات GitHub، ولا تضعها في الملفات أو هذه المحادثة.

## ٤. التفعيل

افتح Actions → Gold news alerts → Run workflow → Run workflow.

انتظر انتهاء التشغيل وظهور علامة نجاح خضراء، ثم تحقق من وصول رسالة «تم تفعيل فحص أخبار الذهب عبر GitHub» على تلغرام. إذا فشل مصدر أثناء المحاولة الأولى، يُحفظ ما نجح ويُعاد الفحص عند التشغيل التالي؛ رسالة التفعيل لا تُرسل إلا بعد نجاح المصادر الخمسة.

بعد أول نجاح، سيجري الفحص عند الدقائق 02 و07 و12 وما بعدها بفاصل خمس دقائق. تستطيع إغلاق الكمبيوتر واستقبال التنبيهات على الهاتف. تأكد من السماح بإشعارات تلغرام ومن عدم كتم البوت على الهاتف.

## الحدود والتكلفة

- المشغل القياسي `ubuntu-latest` مجاني للمستودعات العامة حسب توثيق GitHub الحالي. لا تستخدم مستودعًا خاصًا أو مشغلًا مدفوعًا لهذه الوصفة إن كنت تريد البقاء ضمن الإعداد المجاني.
- الجدولة قد تتأخر، وقد تُسقط GitHub بعض مرات التشغيل عند الضغط. هذه ليست خدمة أخبار لحظية ولا يمكن ضمان استمرارها أو وقت التنبيه.
- في المستودعات العامة، تتوقف الجدولة تلقائيًا بعد 60 يومًا دون نشاط في المستودع. أعد تمكينها وتحقق من سجل Actions عند الحاجة؛ لا يلتف البرنامج على هذا القيد.
- يُحفظ سجل بصمات الأخبار في ذاكرة GitHub المؤقتة. قد تُحذف هذه الذاكرة؛ عند فقدها يُعاد تسجيل الأخبار الحالية دون إرسالها، وقد تفوت أخبار أثناء التهيئة. لا تتضمن هذه الذاكرة التوكن أو معرف محادثتك.
- إذا طال انقطاع الفحص لأكثر من ست ساعات، فلن يعيد البوت إرسال أخبار أقدم من ست ساعات. يُرسل كل خبر متطابق مرة واحدة ما دام السجل محفوظًا. تعديل محتوى الخبر أو فشل حفظ السجل قد يؤدي إلى تكرار تنبيه.
- راقب إخفاقات Actions؛ رسالة واحدة فاشلة أو مصدر متعذر يجعل الدورة فاشلة لتظهر في السجل. لا توجد رسالة تلغرام دورية تقول إن كل شيء يعمل.
- الإيقاف: Actions → Gold news alerts → قائمة الخيارات → Disable workflow. أبقِ النسخة المحلية مغلقة بعد نجاح السحابة لتجنب تنبيهات متكررة من النسختين.
